# API de Juegos (Django + MySQL)

API REST y panel Web desarrollados con Django para la gestión de un catálogo de videojuegos.

Características
Gestión CRUD: Registro, lectura, actualización y eliminación de juegos.

Interfaz Web: Panel administrativo con diseño responsive en Bootstrap.

API REST: Endpoints integrados con Django REST Framework.

Base de Datos: Configurado para MySQL.
